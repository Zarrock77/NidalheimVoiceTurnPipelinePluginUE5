# Code of Conduct

## Our standard

This project welcomes contributions and discussion from anyone, regardless of
experience level, background, or identity. We expect everyone interacting with this
repository — issues, pull requests, discussions, commits — to act in good faith and
with basic respect.

**Expected:**
- Be respectful and constructive, especially when disagreeing.
- Give and accept feedback gracefully.
- Focus criticism on the code and ideas, not the person.
- Assume good intent; ask for clarification before assuming bad faith.

**Not acceptable:**
- Harassment, insults, or personal attacks, public or private.
- Discriminatory language or behavior of any kind.
- Publishing others' private information without consent.
- Sustained disruption of discussions or deliberate derailing.

## Scope

Applies to all project spaces: issues, pull requests, discussions, commit messages,
and any other communication directly tied to this repository.

## Reporting

If you experience or witness unacceptable behavior, report it by opening a private
report via GitHub ([Security Advisories](https://github.com/Zarrock77/NidalheimVoiceTurnPipelinePluginUE5/security/advisories/new))
or by contacting the maintainer directly via GitHub ([@Zarrock77](https://github.com/Zarrock77)).
Reports are handled confidentially; expect an initial response within a week.

## Enforcement

The maintainer may remove, edit, or reject comments, commits, and contributions that
violate this code of conduct, and may temporarily or permanently restrict anyone whose
behavior is harmful or disruptive.

---

This is a lightweight, project-specific code of conduct rather than an adoption of a
longer standard template — appropriate for the current size of this project. It may be
replaced by a more formal standard (e.g. the [Contributor Covenant](https://www.contributor-covenant.org/))
if the project grows a larger contributor base.
